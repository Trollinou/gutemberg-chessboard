# gutemberg-chessboard

A native Gutenberg chessboard block for WordPress, powered by [lichess chessground](https://github.com/lichess-org/chessground) & [chess.js](https://github.com/jhlywa/chess.js).

## WordPress Integration

This package registers a native Gutenberg block so that you can visually configure, drag, and display chessboards inside your WordPress editor and front-end layouts.

### Key Features

- **Interactive Editor Interface**: Configure the chessboard visually in the WordPress post/page editor.
- **Customizable Attributes**: Settings for FEN, orientation, board labels (coordinates), and interactivity.
- **Board API**: Directly control the chessboard using standard JavaScript methods.
- **Custom Events**: Listen for check, checkmate, stalemate, draw, move, and pawn promotions.
